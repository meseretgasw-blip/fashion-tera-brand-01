# ATELIER NOIR

The quiet force of couture. A standalone editorial luxury fashion website for Fashion Tera.

## Technology
Semantic HTML and modern CSS in a single deployable static document.

## Run locally
Open `index.html` directly or run `python3 -m http.server 4173`.

## Cloudflare Pages
Use the repository root as the output directory and leave the build command blank (or use `exit 0`). Nothing is deployed by this project.
